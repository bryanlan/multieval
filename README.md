# LLM Comparison & Evaluation Tool

This Streamlit application allows users to compare responses from multiple Large Language Models (LLMs) for a given prompt and context. It also provides functionality to evaluate these responses using other LLMs.

## Features

-   **Concurrent Inference:** Run inference on multiple selected LLMs simultaneously.
-   **Customizable Prompts:** Define a core prompt, context, and an evaluation template.
-   **Flexible LLM Selection:** Choose from predefined lists of inference and evaluation models.
-   **API Parameter Control:** Adjust temperature and max output tokens for API calls.
-   **Project State Management:** Save and load the entire project state (prompts, selections, results) to a JSON file.
-   **Prompt Set Management:** Save and load just the prompt configurations (core prompt, context, evaluation template) to a JSON file.
-   **Parallel Evaluation:** Evaluate inference results using multiple selected evaluation LLMs concurrently.
-   **Copy to Clipboard:** Easily copy individual model responses and the generated evaluation prompt.
-   **Error Handling & Timeouts:** Robust error handling for API calls, including specific timeout messages.
-   **Progress Tracking:** Visual progress bars for inference and evaluation processes.

## How it Works

1.  **Configuration:**
    *   The user provides a "Core Prompt" and optional "Context".
    *   The user selects one or more "Inference LLMs" to generate responses.
    *   The user can customize an "Evaluation Prompt Template" which uses placeholders to structure the input for evaluation LLMs. Placeholders include:
        *   `{core_prompt}`: The core prompt text.
        *   `{context}`: The context text.
        *   `{response_allmodels}`: All inference model responses.
        *   `{core_response_allmodels}`: Core prompt + all inference responses.
        *   `{core_context_response_allmodels}`: Core prompt + context + all inference responses.
    *   The user selects one or more "Evaluation LLMs".
    *   API parameters like temperature and max tokens can be adjusted.
2.  **Inference:**
    *   When "Run Inference" is clicked, the application makes parallel API calls to the selected inference LLMs via the OpenRouter API.
    *   The prompt sent to inference LLMs is a combination of the "Core Prompt" and "Context".
    *   Responses are collected and displayed.
3.  **Evaluation Prompt Generation:**
    *   After inference, an "Evaluation Prompt" is automatically generated by filling the "Evaluation Prompt Template" with the actual prompts and the collected inference responses.
4.  **Evaluation:**
    *   When "Run Evaluation" is clicked, the application makes parallel API calls to the selected evaluation LLMs using the "Generated Evaluation Prompt".
    *   Evaluation responses are collected and displayed.

## Setup Instructions

1.  **Clone the Repository (if applicable):**
    ```bash
    git clone <repository_url>
    cd <repository_directory>
    ```

2.  **Create a Virtual Environment (Recommended):**
    ```bash
    python -m venv venv
    # On Windows
    venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```

3.  **Install Dependencies:**
    Make sure you have a `requirements.txt` file with the necessary packages.
    ```bash
    pip install -r requirements.txt
    ```
    The `requirements.txt` file should include at least:
    ```
    streamlit
    requests
    pyperclip
    # Add any other specific libraries used
    ```

4.  **Set up API Key:**
    *   Create a file named `keys.py` in the root directory of the project.
    *   Inside `keys.py`, add your OpenRouter API key:
        ```python
        OPENROUTER_API_KEY = "your_openrouter_api_key_here"
        ```
    *   **Important:** Ensure `keys.py` is listed in your `.gitignore` file to prevent accidentally committing your API key.

5.  **Run the Streamlit App:**
    ```bash
    streamlit run app.py
    ```
    The application should open in your web browser.

## Usage Instructions

### 1. Configuration Tab

*   **Project State:**
    *   **Load Project State:** Upload a `project_state.json` file to restore a previously saved session, including all prompts, model selections, API parameters, and results.
    *   **Save Project State:** Download the current session's state to a `project_state.json` file.
*   **Prompts:**
    *   **Core Prompt:** Enter the main prompt you want the LLMs to respond to.
    *   **Context:** Provide any additional context or information relevant to the core prompt. This is optional.
    *   **Evaluation Prompt Template:** Define or modify the template used for generating the evaluation prompt. Use the special tags listed to insert dynamic content.
    *   **Load Prompt Set:** Upload a `prompt_set.json` file to load previously saved Core Prompt, Context, and Evaluation Template.
    *   **Save Prompt Set:** Download the current Core Prompt, Context, and Evaluation Template to a `prompt_set.json` file.
*   **LLM Selection:**
    *   **Select Inference LLMs:** Choose one or more models from the dropdown list to generate initial responses.
    *   **Select Evaluation LLMs:** Choose one or more models from the dropdown list to evaluate the inference responses.
*   **API Parameters:**
    *   **Temperature:** Adjust the creativity of the model's output (0.0 to 2.0).
    *   **Max Output Tokens:** Set the maximum number of tokens the model can generate.

### 2. Output Tab

*   **Run Inference:**
    *   Click this button after configuring your prompts and selecting inference LLMs.
    *   The application will fetch responses from the selected models.
    *   Progress will be shown, and results will appear below.
*   **Inference Results:**
    *   Each model's response is displayed in an expandable section.
    *   Click the "Copy Response" button within an expander to copy that specific response to your clipboard.
    *   If the inference process seems stuck, a "Clear Any Stuck Processes" button may appear; clicking it will try to reset and rerun the UI.

### 3. Evaluation Tab

*   **Generated Evaluation Prompt:**
    *   This text area displays the prompt that will be sent to the evaluation LLMs. It's automatically generated based on your "Evaluation Prompt Template" and the inference results.
    *   It is updated automatically if inference results are available and the template or underlying data changes.
    *   **Copy Eval Prompt:** Click to copy the entire generated evaluation prompt to your clipboard.
*   **Run Evaluation:**
    *   Click this button after inference is complete and you have selected evaluation LLMs.
    *   The application will send the "Generated Evaluation Prompt" to the selected evaluation models.
*   **Evaluation Results:**
    *   Each evaluation model's response is displayed in an expandable section.
    *   Click the "Copy Eval" button within an expander to copy that specific evaluation to your clipboard.

## Model Lists

The application uses predefined lists of inference and evaluation models (`INFERENCE_MODELS` and `EVALUATION_MODELS` in `app.py`). You can modify these lists directly in the `app.py` file to include different models available through OpenRouter. Make sure the model identifiers are correct as per OpenRouter's documentation.

## Error Handling

*   The application includes error handling for API requests, including timeouts and unexpected response structures.
*   If the `OPENROUTER_API_KEY` is missing from `keys.py`, an error message will be displayed.
*   Warnings will appear if necessary inputs (like core prompt or selected models) are missing before running inference or evaluation.
